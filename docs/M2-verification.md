# M2 促销毛利调查切片验证记录

日期：2026-10-15。范围为单条促销毛利异常的只读调查，不代表完整 M2 或审批执行闭环完成。

## 已交付

- 商品毛利预警 / 待补证行的“开始调查”按钮，以及“调查记录”标签页。
- 原桌面内的调查详情：状态、冻结快照、工具证据引用、观察、假设、替代解释、未知项、两个条件方案、串行 Reviewer 和失败重试。
- 复用现有默认 API 连接和凭据存储的推理 Adapter；支持 Anthropic Messages 和 OpenAI Chat Completions 兼容 API / 本地模型。明确拒绝暂不支持的 OAuth、云身份和协议。
- 只读白名单工具与有预算的模型决策循环。无 Shell、文件访问、任意 SQL、通用 MCP 或业务执行接口。
- 独立调查账本、进行中唯一性、每空间两项并发上限、五分钟到期恢复、冻结证据和中间过程持久化。
- 离线规则演示明确标注，绝不在模型失败时自动替代模型结果。
