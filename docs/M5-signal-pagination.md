# 库存与广告分页：领域查询与桌面接入

2026-10-18，接续 [PRD 追踪矩阵](PRD-traceability.md) A4/F03/G08。

## 已完成

`SignalStore.page()` 提供库存/广告、来源、店铺、渠道、日期、状态和字面搜索筛选；默认返回 30 条，最多 200 条。固定排序加 ID 保证跨页稳定，越界页码回到最后有效页。

返回值分别包含筛选后总数和业务范围内两类场景的正常/预警/补证计数。范围计数不受搜索、状态和页码影响，不能用当前页数量代替总数。

`signals_page` 通过现有受信 IPC 与 Bun worker 提供分页查询，不接受客户端指定 Workspace、数据库路径或 SQL。默认经营快照附带的库存/广告数据、场景导入和演示载入回包也限制为 30 条，并保留范围计数及来源内全部店铺/渠道/日期选项；避免主表虽然分页，外围快照仍传输全部记录。

库存与广告页面和异常中心已接入该请求：每个场景独立页码，筛选、来源变化和手动刷新重置页码；界面只展示当前查询对应的响应，旧筛选结果不回填。导出明确为“当前页证据”，附分页信息，不再把当前页称作全部筛选结果。

查询使用 SQLite 可重建投影；源记录、批次和规则变化使其失效。重建复用完整快照计算，所以某个 SKU 的跨日期规格冲突不会因为分页过滤而被掩盖。投影检查、重建、范围计数和分页读取处于同一事务；只读 MCP 连接继续读取原始快照，不写入投影。

本轮领域与真实 worker 专项共 27 项、129 次断言通过，覆盖跨页无遗漏、独立范围计数、所有范围筛选、字面搜索、其他连接导入与替换、批次时间变更、重启、跨日期规格冲突、分页输入限制和只读连接。worker 使用每场景 65 条合成记录验证 30 条回包、完整总数、页外选项和重复导入。领域与 Electron 类型检查、主进程与界面构建、静态翻译键覆盖检查通过。

专项命令：`bun test packages/retail-domain/src/signal-query.test.ts packages/retail-domain/src/signals.test.ts scripts/merqo-signal-pagination.test.ts`。真实 worker 专项已加入 CI 配置，本轮尚未推送触发云端检查。
