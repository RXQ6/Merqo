# M2 三场景只读调查

本轮补齐促销毛利、缺货风险、广告回报的调查核心、条件方案、串行 Reviewer、独立只读 MCP 和版本化 Skill。沿用原桌面 AppShell 与主题，不提供审批或经营写入。

## 手工验收

1. 在项目根目录执行 `bun run retail:build`，然后 `bun run retail:start`。已打开的旧窗口需退出并重新启动。
2. 原侧栏进入“经营分析”，在“数据与导入”载入演示数据。毛利页及“库存与广告”中的预警 / 待补证行都有“开始调查”。
3. 在设置中配置 API 模型，设为工作空间或全局默认。点击“开始调查”会创建模型调查；缺连接、凭据或契约不符会显示失败，绝不自动生成演示报告。支持 Anthropic Messages、OpenAI Chat Completions 及采用这些协议的 Pi provider（包括 DeepSeek）。本适配器不支持 OAuth、云身份或 Responses-only 连接。
4. 没有模型时，明确点击“运行离线规则演示”。状态和复核必须显示未调用模型。
5. 分别选择 TEA-500 的三种场景，核对下面的代码测算。逐条展开事实、假设、替代解释、待补证和原始工具证据，点击引用定位到证据。
6. 对库存 / 广告 OAT-1000 待补证记录运行离线演示。补货草稿量 / 调整后花费须显示“待补证”，约束未通过；模型复核不能解除缺字段阻断。
7. 在“调查记录”切换三个场景，退出再启动，历史报告及创建时冻结的证据必须保留。导入修正不会改写历史调查。新调查的四个工具过程应显示“MCP只读查询”。

| TEA-500 场景 | 应见结果 |
| --- | --- |
| 促销毛利 | 原收入 ¥70、毛利 ¥10、毛利率14.29%；券从¥20降至¥15的条件值为收入¥75、毛利¥15、20.00% |
| 缺货风险 | 可售40，日均20，覆盖2天；5天交期加2天缓冲，目标库存140；晚到在途不抵减，草稿100；因交期超过覆盖期而阻断，不能声称消除到货前缺口 |

## 独立 MCP

在同一项目根目录启动（将路径和记录ID替换为实际值）：

```powershell
bun scripts/merqo-retail-mcp.ts --workspace "D:\实际Workspace目录" --scenario inventory --record "冻结快照中的id"
```

- Workspace 须为已存在的本机目录，数据库位于其 `retail/` 下；启动时由操作者选定唯一记录。客户端不能提交路径、店铺范围或 SQL。
- 场景选项为 `margin`、`inventory`、`ads`。每个进程只暴露四个场景工具；健康、SKU、促销/库存/Campaign、方案测算。
- 使用标准 MCP stdio。stdout 只输出协议消息；工具参数严格为空对象。客户端可读取 `merqo://skills/{scenario}` Markdown 资源。
- 数据库只读打开，不创建或迁移表。选定证据在启动时冻结，后续导入不改变该进程看到的内容。
- 返回证据ID、来源摘要、规则与批次、业务日期、读取时间、范围及 partial 标志。不提供写工具。
- 桌面调查已通过标准 MCP stdio 调用固定服务，并从MCP资源加载Skill。启动参数为服务端确定的Workspace与run ID；服务只读加载该调查冻结证据。主进程验证范围、证据摘要、批次与规则，失败不降级到进程内工具。旧调查历史保留原transport标识。

## Skill 与执行边界

`packages/retail-domain/skills/{margin,inventory,ads}/SKILL.md` 是可复用、版本化的调查指令，桌面运行时实际读取它们。`bun run retail:skills` 从核心契约重新生成；构建时复制为应用资源。可单独交给支持 Markdown Skills 的客户端加载，未自动安装到通用 Agent 的 Skills 列表。

主进程复用安全凭据存储，直接推理请求不暴露通用 Agent 工具。单次请求最多90秒；调查总计5分钟、最多12次决策和一轮 Reviewer（格式错误最多额外纠正一次）、每工作空间最多两项活动调查。最多两次格式纠正计入12次预算；格式错误请求不执行，保留纠正事件。无效引用、缺工具或错误方案类型仍被拒绝。Reviewer根对象只允许verdict与字符串数组notes；纠正失败会显示阶段和字段，不接受无效复核。

调查账本位于 `operations.sqlite.investigations.sqlite`。冻结快照与报告保存在 SQLite。旧毛利记录无需迁移；终态不接受迟到结果。退出中的调查在原期限到期后失败，支持显式重试，未实现自动续跑。
