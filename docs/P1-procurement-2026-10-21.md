# 采购到货与批次效期账本

开发版入口：经营分析 → 库存与广告 → 采购到货与批次效期。下载JSON示例，导入预览并确认，按独立采购来源、店铺、仓库和截止日期查询，可导出结果。

不可变事件包括采购计划、预计到货日期更新、取消和分批到货。采购行按来源/店铺/仓库/采购单/行隔离，SKU规格不能变化。累计取消与到货不能超过计划，事件不能超前，变化和到货不能早于计划。同事件内容重复去重，不同内容拒绝。到货须明确合格与待处理数量，两者之和等于到货件数；本地声明不构成认证仓库数据。

采购预计日期可明确更新为未知，同一行同一时刻不能有两个日期更新。预览绑定全采购账本摘要，账本变化后必须重新预览。确认与回执同一事务追加；同文件重复确认返回原回执并提示本次未新增。

同来源、店铺、仓库、SKU规格及批次的明确效期不能冲突。未知效期不补默认值。查询展示当前已知、截至业务日期的计划/到货/未到/逾期，以及累计到货批次的已过期、30天内到期和缺失效期数量。不是历史当时知识快照。批次提示不代表当前仍有库存，已经消耗的批次也保留历史。

到货合格数量不会自动增加可售库存，不修改原库存快照、交易、退款、实物退回质检或执行权限。尚未实现仓库收发存和调拨、实际库存回写、采购付款成本、供应商管理、退回质检入库联动、平台ERP/WMS认证或Agent调查接入。

每文件8MB、最多2000事件；工作空间采购事件最多50000条。界面前100采购行和批次，合计全筛选范围；最近20份工作空间回执不受筛选限制。记录存于已有交易数据库，纳入上一批经营备份恢复，领域测试已验证恢复后结果一致。

样例计划10件，到货4件（合格3、待处理1），未到6；截止10月21日，原预计10月16日，逾期未到6。证据见[验收](verification/procurement-2026-10-21/report.md)。仍仅开发版，未打包发布。
