# Merqo beta.10：经营导航调整

日期：2026-10-22。解决原侧栏二十多个功能纵向堆叠、需要滚动寻找、选中层级不清楚的问题。本次改变导航与窗口布局，保留所有业务页面、证据与关联跳转；不改变业务数据 schema11、审批或执行规则。

## 软件布局

左侧常驻5个业务分组、一个经营助手入口、功能搜索及最多5个常用入口。顶部仅展示当前分组的功能。分组和具体页面分别只有一处选中；收藏区不重复强调选中状态。

| 一级分组 | 二级功能 |
| --- | --- |
| 经营总览 | 总览、库存与补货、广告经营、交易与退款 |
| 异常与调查 | 异常中心、业务实体、调查记录、经营巡检 |
| 任务与决策 | 业务任务、复查与提醒、决策草稿、审批中心、执行记录、补偿记录 |
| 知识与复盘 | 经营知识中心、经营复盘 |
| 数据与设置 | 平台接入、数据与导入、商品映射、经营规则 |

批量执行保留为执行记录的子页，也可通过功能搜索直接进入。经营助手为独立固定入口。全部22个页面均保留。

## 使用方式

- 点击左侧分组，打开该分组上次查看的功能；首次进入打开第一项。
- 在顶部切换功能。当前功能在窄区域仍保持可见，其余进入“更多”；菜单支持方向键和 Esc，关闭后焦点返回按钮。
- 左上“搜索功能”或 Ctrl+K 搜索名称和关键词，例如缺货、审批、Wiki、备份；Enter 打开首项，Esc 返回。搜索只查功能目录，不读取业务正文。
- 页面顶部星标加入/移除常用，默认业务任务、库存与补货；最多5项。按工作区 ID 在本机 localStorage 保存，真实进程重启仍保留；不宣称跨设备同步。
- 950像素及以下默认折叠为图标栏，可手动展开；经营窗口最小宽度支持800像素。图标保留名称提示和无障碍标签。
- 左侧异常分组与异常中心显示原有已加载经营范围计数，没有虚构待审批或待办数字。
- 调查、任务、方案、执行、复盘、知识之间的原关联跳转保持原目标，并根据页面自动切换两级导航。
