# DeepSeek 动态模型列表

2026-10-20，本地开发版已实现；先前生成的 beta.4 候选安装包未包含本次改动，GitHub beta.3 也未更新。

## 使用入口

设置 → AI → DeepSeek 模型。每个 DeepSeek 连接展示完整 API 返回列表、原始调用 ID、上下文、最大输出、图片支持及推理档位，可刷新和设为该连接默认模型。未返回的能力显示“未知”。现有会话或 Workspace 显式覆盖仍按原有优先级生效。

启动、连接验证/凭据设置成功时，沿用现有后台刷新流程，请求连接地址的 `GET /models`；按钮使用同一 RPC。密钥由服务端凭据管理器读取，不传给列表组件。失败只展示安全的状态码/网络提示，不展示接口响应正文；禁用重定向，避免授权头跟随跳转。

成功列表和能力随配置持久化，记录最近成功和尝试时间；失败保留列表和默认模型，标注缓存。尚未同步的静态列表明确标注预置。新列表不包含原默认 ID 时保留原选择并提示，不自动替换。动态列表跳过旧 SDK 目录的启动覆盖逻辑。运行时在 DeepSeek provider 下注册发现的新 ID，保留 SDK DeepSeek 协议，并传递能力元数据。
