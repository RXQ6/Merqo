# 未结清订单的部分取消

2026-10-20，开发版实现并通过本机合成验收。入口：经营分析 → 交易与退款 → 下载部分取消示例；导入后在取消事件金额下展示取消原标价。

新增可选字段 `cancelled_basis_minor`，单位整数分，只能用于未结清时的取消事件，声明该次取消部分的原标价，不是实际退款。部分取消必须提供，不能把总价按件数均摊；该字段可在平台通用事件映射中单独配置，沿用映射选择的金额单位。逐行参考文件也支持该列。

取消后，累计收款＋商家优惠−平台补贴的结清目标为原标价减累计取消标价，唯一结清支付确认未取消的全部件数。发货上限为实际结清件数减结清后取消的件数。累计取消和发货不能超过原单数量，超额、缺标价或错误结清数量整批拒绝。

部分取消不能使剩余应结标价低于已有结算；此类来源需要拆分原单或提供明确更正，本版不自行冲减收款。取消剩余全部件数时可省略取消标价，关闭订单行，已收款仍需独立退款。结清后取消不能提供该字段，也不会改写原结算。原有整行取消、分次支付和结清后取消兼容。

样例：3件10001分，首付款2000分；明确取消1件3333分；再支付4668分确认剩余2件，发货2件。收款共6668分，无自动退款、实物退回或库存调整。支持分批导入、重复去重和重启留存。

仍未实现真实平台取消响应映射、自动退款、真实仓库入库、换货差价及完整促销资格。证据见[验收记录](verification/partial-cancellation-2026-10-20/report.md)。
