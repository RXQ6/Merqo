# 经营工作台第一批：导航与排版

日期：2026-10-21。对应本轮开发路线的「入口盘点 → 统一排版 → 业务导航与高级能力边界」。本批调整现有功能的组织和呈现，不增加真实平台执行权限。

## 用户进入后的主线

经营总览 / 异常中心 → 选择商品与经营期间 → 只读调查与补证 → 决策草稿 → 本地模拟审批 → 模拟执行与补偿 → 经营复盘。

库存支线：库存与补货 → 销量与缺货风险 → 采购到货与批次效期 → 仓库收发存、调拨及预占。

广告支线：广告经营 → 广告回报变化 → 退款后归因核对。

售后支线：交易与退款 → 交易事件查询 → 换货差价 / 退回质检 / 费用与结算贡献 / 订单优惠分摊 / 促销资格与赠品成本。

## 本批落地内容

| 范围 | 实现 | 边界 |
| --- | --- | --- |
| 经营现场 | 总览、异常、库存与补货、广告经营、交易与退款 | 原「库存与广告」拆为两个独立页面；异常中心仍可并列核对两类异常 |
| 分析与跟进 | 经营助手、调查记录、巡检、经营复盘 | 助手提供真实场景入口；当前不是自动携带任意商品上下文的自由对话系统 |
| 决策与模拟执行 | 草稿、审批、执行记录、补偿；执行记录内保留执行批次 | 单用户本地模拟；没有真实改价、采购、广告调预算或仓库写回 |
| 数据与设置 | 平台接入、数据与导入、商品映射、经营规则 | 真实抖店接入仍取决于应用开通、店铺授权和接口验收 |
| 高级工作台 | 业务窗口顶部和助手页提供入口；原工作台增加用途说明 | API、MCP、本地资料、技能、项目、通用自动化继续可用；未删除或迁移现有会话、状态、标签 |
| 页面标题 | 共享 `PageHeader`，每个经营页面一个一级标题，二级功能标题与说明分层 | 原有调查、审批和执行详情仍保留各自业务内容 |
| 排版 | 统一标题基线、正文行距、说明宽度、卡片留白、操作间距、表格滚动区域 | 不是给每个业务模块增加新规则 |
| 表单 | 宽窗口两列，窄窗口一列；说明、复选确认、结果、操作区横跨整行 | 不更改业务字段、计算或人工确认约束 |

## 入口盘点与验收范围

全部 17 个一级入口，以及执行记录内的执行批次，共 18 个页面纳入走查：经营总览、异常中心、库存与补货、广告经营、交易与退款、经营助手、调查记录、经营巡检、经营复盘、决策草稿、审批中心、执行记录、补偿记录、平台接入、数据与导入、商品映射、经营规则、执行批次。

验收脚本：`scripts/merqo-business-layout-check.cjs`。使用隔离合成数据配置，通过真实 Electron、preload 和 IPC 读取；检查 1440 与 800 宽度下的页面标题、横向溢出、场景分离、8 次功能定位、助手跳转、高级工作台往返，以及总览进入 CSV 预览。验收不确认导入，也不调用模型或真实平台。

分页回归：`scripts/merqo-signal-pagination-ui.cjs`。分别进入库存和广告页面，对每类 65 条合成记录检查分页、末页导出、搜索、状态、完整范围计数、页外店铺筛选和刷新；异常中心继续校验两类并列异常。

本轮只涉及界面与导航，未修改 domain 计算或数据库契约。原 371 项 domain 测试结果属于上一批基线，不冒充本批新运行结果。具体运行证据见本批验收记录。

## 下一条开发链路

业务实体与证据关联 → 从实体进入带上下文的经营助手 → 可持久化的业务任务状态与跟进 → 场景标签、经营方法和专题 → 平台授权后的真实数据验收 → 业务巡检与自动化联动 → 结果复盘 → 干净环境和跨 Windows 版本验收 → 更新安装包。

这些后续能力不能通过改名视作完成。通用会话的「待审查」仍是会话状态，不是经营审批；通用项目和标签也尚未替代业务任务、商品或店铺实体。当前 published beta.5 安装包不包含本批界面变更。
