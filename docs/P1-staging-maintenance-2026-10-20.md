# 加密暂存维护

2026-10-20，开发版入口：经营分析 → 平台接入 → 加密暂存维护与清理。

## 操作流程

查看保有加密原文的任务数量和内容大小 → 设置保留天数（至少7天） → 生成预览 → 核对任务清单、截止创建时间与摘要 → 勾选确认 → 清空本次预览的加密原文 → 查看清理回执。

修改保留天数后，旧预览不能直接确认，须重新生成。重启后显示的历史预览也须重新预览后才能确认未执行的计划。每次最多100个任务、64 MB加密内容，更多候选分批处理。

## 可以清理哪些

必须同时满足：

- 任务拉取完成，创建时间早于所选截止时间，且未清理。
- 已存在确认入库回执；所有该任务预览均已确认且没有隔离记录。
- 不在增量计划的待完成任务位置。
- 清理前任务、暂存内容、入库及预览状态与清理预览一致。

近期、运行中、失败、含隔离、未入库或存在未确认预览的任务不会被列入。空结果且没有入库回执的任务目前也不列入；后续需单独定义空任务归档规则。

## 清理后保留什么

只清空同步页中的加密原文字段，保留分页回执、计数及响应摘要、同步任务、业务交易事件、入库回执、映射、对账、隔离处理和清理审计。任务标记原文已清空，不能再次从该暂存检查字段或生成映射预览；需要重新拉取。已入库结果和对账仍可查看。

清理计划和回执不可覆盖，重复确认返回同一次执行结果。历史回执展示最近20项。确认使用同一SQLite连接附加交易数据库，在IMMEDIATE事务中核对入库/预览并清空暂存，避免核对后出现新待处理预览却继续清理。只修改同步数据库，不删除交易数据或密钥。

显示的是加密字段的逻辑内容大小。SQLite空闲页、WAL、既有备份可能继续占用空间；本功能不是安全擦除，也不保证数据库文件立即缩小。未实现完整数据库压缩、备份/恢复及跨机凭据恢复，不能将“清理”描述为这些工作完成。

## 验收范围

领域验证覆盖：只清空旧的已确认无隔离任务、保留业务/分页回执、重复确认幂等、新预览使旧清理计划失效、近期/隔离/未确认任务排除。

实际桌面验收使用已完成的隔离合成配置，只在应用关闭后把两个合成任务的创建时间改为10天前，以模拟保留期。不是实际运行10天，也未触及用户正常配置。验证清单只包含无隔离任务，清理后业务事件及页回执不变、旧暂存不可读、重复确认只有一份回执、重启后仍保留记录。结果见[验收归档](verification/staging-maintenance-2026-10-20/report.md)。
