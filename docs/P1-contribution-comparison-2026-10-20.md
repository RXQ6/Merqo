# 跨期收款与结算贡献比较

2026-10-20，开发版已实现。入口：经营分析 → 交易与退款 → 五类费用与结算贡献核对 → 跨期比较。

先为两个原订单窗口分别上传费用并冻结报告，再选择基期和观察期。仅比较同来源、同店铺/渠道筛选、相同天数且不重叠的窗口；观察期须晚于基期，上海时区当天尚未结束，不能参与比较。每份报告都按当前已知交易和退款核对，不是当时的期末知识快照。

费用缺失或观测过早时保持待补证，不补零。符合口径后展示收款、退款及五类净费用变化；各项数值影响之和必须严格等于结算贡献变化。收款增加但贡献下降会单独提示。实体集合变化或明细截断会提示构成限制；实体集合相同也不表示销量结构相同，数值拆解不代表因果归因。

比较记录绑定两份报告ID和输入摘要，独立追加保存，之后导入不会改写旧结果。可查看最近20份比较并导出JSON。费用仍是人工声明，未覆盖税项、净负费用或完整净利润，也未接入Agent调查。

本机合成验收：基期收款100元、商品净成本50元，贡献50元；观察期收款120元、商品净成本90元，贡献30元。界面显示收款+20元、商品净成本影响-40元、贡献-20元；反向日期被拒绝，实际重启后比较仍保留。未调用真实平台。
