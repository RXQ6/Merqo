## 本轮实现

毛利调查现在明确区分快照描述、条件算术、因果归因和真实经营结果。Reviewer 按实际报告主张核对证据；虚构、错误归因、把商品毛利当净利、承诺收益或谎称没有证据缺口仍拒绝。没有自动把拒绝改为通过。[真实模型记录](M5-live-evaluation.md)保留全部三批，后续通过不能抹去先前错误。

毛利 CSV 导入支持最多十万行、32 MB；服务端每页默认 30 行、最多 200 行。可重建的 SQLite 查询投影和索引缩小返回数据；变更触发失效，权威计算仍来自原有领域规则。搜索与翻页不改变完整作用域的总额，金额使用 BigInt 精确累计。导入/重建约需数十秒，worker 导入超时为 120 秒；这不是两秒导入承诺。预览只返回前 30 条，导出当前页已明确标示。

性能脚本覆盖十万行毛利总额、状态筛选及首页/深分页，30 次均启动新 worker 和 SQLite 连接，计入进程与传输时间。OS 文件缓存已由导入预热。先前基线 p95 为 1560.812 ms，增加覆盖索引后为 528.187 ms；当前源码复测 p95 **899.382 ms**、导入 **45.526 秒**，完整逐次记录见 `performance-final.json`。机器为 Ryzen 9 7945HX、32 逻辑 CPU、约 16 GB 内存、Bun 1.4.2。分页页面另用实际安装程序的 120 条数据验收，未把该 UI 测试说成十万行渲染测试。

暂停操作先持久化状态与 epoch，再取消待返回请求；旧执行器的迟到结果因 epoch 不一致无法覆盖新运行。恢复沿用工具记录与冻结证据，不重复已完成工具，累计模型请求最多 14 次。用户点击继续会显式新增五分钟执行期限，界面有说明；不会补满调用预算。暂停、重启、过期中断恢复及预算耗尽有回归覆盖。

AgentBackend 新增可选的隔离 completion 能力，桌面调查通过实际 Backend 实例创建并在结束时关闭。配置、凭据解析、用量和限时 HTTP 推理实现在 shared 层复用；该能力没有聊天工具注册、Shell、通用 MCP 权限或 SDK 子进程。它不是复用整个通用聊天执行循环；领域工具仍必须经过冻结作用域校验。

- **外部环境**：干净 Windows 虚拟机/新账户与其他 Windows 版本未验证；当前主机去除开发工具 PATH 的测试不能替代它们。用户已有确认，环境可用后再补验。

- **生产化**：真实平台写入、多人身份授权、实盘经营效果、签名与自动更新仍未交付。
