| 类别 | 样例数 | 当前验证范围 |
| --- | ---: | --- |
| 券与满减叠加 | 3 | 导入后商品单件收入、毛利、合计、基点及缺成本状态 |
| 多规格 | 3 | 同店同渠道 SKU 跨日期规格冲突，空规格隔离 |
| 组合装 | 3 | 未支持：子项、件数、成本分摊明细映射 |
| 赠品 | 3 | 未支持：赠品关联和成本/优惠分摊 |
| 会员价 | 3 | 未支持：身份、有效会员价、优惠互斥 |
| 平台补贴承担方 | 3 | 明确额外平台结算，商家承担或未知时补证 |
| 延迟数据 | 3 | 固定时钟下 CSV 导入时效校验，不证明事件数据实时性 |
| 无货价格 | 3 | 未支持：有效可售报价筛选及报价规格匹配 |
| SKU 错配 | 3 | 工具上下文与冻结身份一致、错配和缺引用拒绝；不验证外部目录匹配 |
| 异常销量 | 3 | 相邻等长窗口销量下降至少 20% 与缺数；不覆盖异常暴涨或缺货因果 |
| 毛利冲突 | 3 | 数值证据一致、篡改单件毛利、缺优惠工具证据 |
| 广告归因窗口 | 3 | 同口径正常、ROAS下降边界、归因窗口错配 |
| 审批与执行故障 | 12 | 未批准、过期、摘要篡改、跨空间、伪造角色、幂等、旧版本、回执落盘失败、重开账本、回读漂移、批次部分失败、UNKNOWN恢复 |

12 个未支持样例仅登记三种不同输入及目标约束，**不执行、不计为通过，也不证明应用已能阻断此类数据**。尤其当前 CSV 对未映射额外列的处理不能替代赠品、会员价等业务契约。不得把普通 SKU 毛利计算解释为这些场景已交付。

业务样例直接调用现有 RetailStore、SignalStore、数值核验和时效策略，审批/执行样例调用真实 DecisionStore 与模拟账本；没有复制一套计算公式代替生产代码。故障准备使用本地模型/Reviewer 协议夹具，只为了构造审批前置状态，不计入真实模型质量。UNKNOWN 使用合成时钟推进 16 秒；本套不能证明真实网络超时、进程中断或并发竞态行为，相关既有集成测试须另外保留。
