# M3 模拟补偿申请与再审批

后续执行批次、待确认恢复与部分成功切片见[M3批次验收](M3-batches-acceptance.md)及[验证记录](M3-batches-verification.md)；下文保留本轮单动作补偿的历史范围和结果。

范围：成功模拟回执→补偿申请与不可变修订→独立批准/驳回→模拟补偿→回读核对及重启。沿用原桌面主题，两栏补偿记录页从成功回执进入。不实现真实平台写入、多动作部分成功或经营效果复盘。

补偿是新的动作和授权，绑定原执行job/receipt摘要、当前模拟资源完整版本摘要、当前演示证据与规则、目标值、理由及30分钟有效期。原批准过期不会抹去历史执行，也不自动授权恢复。一个原执行只允许一个补偿流程；修订替代旧授权，成功后全流程不能再执行。当前状态必须仍与原成功回执after完全相同，不能靠新版本“重新绑定”覆盖后续动作。

默认目标由原回执before推导，浏览器不传金额、范围或角色。毛利恢复按当前证据重新计算，低于毛利下限阻断，不能以补偿理由绕过；广告仅恢复原模拟预算，不声明收入效果；库存仅取消本地pending补货请求，accepted或状态不明时转人工，不能直接增减现存/在途。v3只建pending请求，兼容其无状态字段的旧回执；新执行明确标记pending，取消后标记cancelled。

申请、审批、失效、执行尝试和核对独立留痕。IMMEDIATE事务内再次检查Workspace、绑定、证据时效、规则、目标版本和申请有效期；失效发现写入后锁定，证据或时钟恢复不会复活。相同结论与理由重试幂等，冲突结论拒绝。补偿效果、唯一回执与首次核对在同一savepoint内提交；失败回滚效果，保留尝试；响应丢失先刷新，成功重试返回原回执，不重复恢复。

决策库升级v4，v1-v3升级前一致性备份，未来版本拒绝。核心测试：未审批、错误角色/版本/hash/跨工作区、过期、证据变化、低毛利恢复、受理补货拒绝取消、目标后续变化与ABA、并发重复、写失败回滚、响应丢失、修订/驳回/历史和迁移恢复。单用户模拟角色不保证独立审批身份。
