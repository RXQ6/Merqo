# Merqo 0.1.0-beta.3 — Windows Preview

本版本将交易退款、商品映射、联合证据与补证流程接入经营工作台，并补齐本地模拟流程的最终复盘和通用会话写入边界。

- **交易与退款**：下单/支付/发货/部分退款事件账本，按事件期或原订单期查询；跨期退款可显示负值；CSV整链校验、幂等、不可变历史与分页。
- **商品映射**：显式SKU/规格/广告活动映射，可修订停用，按来源、店铺、渠道及有效期匹配，保存审计历史。
- **调查记录**：冻结共同窗口、最慢完整水位及映射版本；缺失、跨窗或歧义保持待补证。支持变化预览、确认后创建子调查，最多两轮，保留旧报告与审批。
- **经营规则及决策**：独立SKU改价、店铺策略与审批有效期配置，来源观测/覆盖声明；审批绑定版本及摘要，实际过期拒绝执行。
- **安全**：经营空间的通用Agent会话强制只读，Auto不开放Shell、文件写入或任意MCP；模拟写入仍由专用审批执行。

验证：领域280项、2167断言通过；固定业务48/48；实际只读MCP通过。三场景均走通调查→草稿→审批→模拟执行与回读→观察→最终Case，包含驳回重提、过期拒绝和重启留存。真实模型每场景5次中4次通过，禁止动作事件0，3次失败保留。十万行数据各30次查询p95：毛利879ms、库存540ms、广告521ms。

安装、重装、升级及卸载的对应结果见[最终验收记录](../verification/route-final-2026-10-19/report.md)，仅以已记录通过的范围为准。

范围：Windows x64未签名预览，本地分析和模拟执行；CSV来源声明不代表平台认证。单次全额支付、外部提供行级优惠分摊，不支持分次支付、取消换货、复杂嵌套组合装或自动订单级优惠分摊。联合证据为并列描述，不推断因果。真实平台接入/写入、多用户可信身份、干净Windows及跨Windows版本验收尚未完成。完整PRD不标记100%。
