## 本次交付

毛利、库存、广告 CSV 导入预览新增“来源与完整水位（可选）”：来源标识、名称、独立源观测时刻、覆盖开始（包含）、完整截止（不包含）、完整性声明。页面按北京时间填写，持久化保留时区；完整截止必须晚于开始且不晚于观测时刻，观测时间不能超过本机时间五分钟。半填、无效范围或冒充内置来源标识被拒绝；全部留空保留原有未知来源行为。

批次记录原 CSV 内容 SHA-256，元数据参与批次摘要。相同文件、映射和声明幂等；声明修正形成新批次，旧批次和已冻结调查保留原声明。工具健康信息、调查页、证据详情及 Markdown/JSON 导出携带相同来源信息，模型报告的未知项明确保留未验证身份和窗口缺口。

源观测时效独立于导入时效和业务日期。旧源观测不能因重新导入变新；不完整窗口、当前窗口未覆盖、库存/广告基线窗口未覆盖均有明确补证原因。内置演示的观测和水位由确定性合成业务时钟生成，明确标为合成来源，不冒充真实平台采集时间。

旧批次不补造来源元数据；重新打开旧调查仍显示未知。毛利元数据以附加批次表保存，旧只读连接在缺表时仍能读取原记录。CSV 声明始终标记 `operator_declared / unverified_declaration`，保持仅分析环境，不因此获得执行资格。
