# Merqo 0.1.0-beta.6

本次更新将 beta.5 之后已完成的功能合并到新的 Windows x64 安装包。发布前进行本机隔离安装验收；不覆盖 beta.5 历史资产。

- 修复关于页残留 `0.11.4`：统一 Merqo 版本来源，安装版显示实际包版本，源码版单独标注。
- 更新检查接入 RXQ6/Merqo GitHub Releases，支持 beta；失败不再误报最新。当前采用查看发布、手动下载安装，不自动执行安装器。
- 导航按经营现场、分析跟进、模拟执行、数据设置分组；库存与补货、广告经营拆为独立页面，新增经营助手场景入口，统一标题和表单排版。
- 平台接入准备：同步任务、断点重试、增量补拉、明确事件映射、入库预览、质量隔离、独立对账、暂存维护与加密备份。
- 交易售后：部分取消、退回质检、费用与结算贡献及跨期比较、整行换货差价核对、优惠分摊和促销资格预览。
- 库存采购：采购到货、批次效期、仓库收发存、调拨异常、盘点更正、预占与释放、按效期拣货计划及确认预占。
- 广告：退款后的声明归因与结算核对。

真实抖店尚未授权接入；审批、执行和预占仍是本地模拟或声明账本，不会修改真实平台。新经营助手为场景入口，实体上下文对话和业务任务系统仍待开发。

安装包未签名。本机验收不代替干净虚拟机、其他 Windows 版本或真实平台验收。旧安装包的检查逻辑不会被远程改写；首次升级请从本版 Release 下载新安装包。

源码修复证据见[更新检查修复](update-check-fix-2026-10-21.md)和[经营界面验收](verification/business-workbench-2026-10-21/report.md)。安装验收与发布结果见下方记录。
