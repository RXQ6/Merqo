# 经营数据备份与恢复

开发版入口：经营分析 → 平台接入 → 经营数据完整备份与恢复。

创建时输入并确认至少12字符密码，通过系统对话框选择 `.merqo-backup` 文件。备份包含当前工作空间已有的六类经营SQLite：经营快照/规则/商品映射、库存广告信号、调查/决策/审批/执行、巡检、同步及增量位置、交易/入库/费用/质检。包含未清理加密暂存页及其解密密钥、当前接入凭据。不会复制其他工作空间、聊天/附件、AI模型密钥或历史迁移备份副本。

备份期间暂停接纳该工作空间的新经营worker，等待现有worker退出；同一SQLite连接附加所有已有数据库并获取IMMEDIATE锁，序列化包含已提交WAL页的快照，检查完整性、版本及暂存解密。之后释放排队请求。不会把数据库文件与不同时点的WAL直接复制拼接。当前上限64MB数据库、100MB加密文件。

包采用scrypt（N=32768,r=8,p=1）派生密钥及AES-256-GCM认证加密；随机盐和IV。密码不写入备份或命令行参数，解密内容仅在worker内处理。忘记密码无法找回。

恢复先选择文件、输入密码并校验。界面仅显示来源名称、时间、数据库大小与摘要、凭据数量。预览绑定窗口/当前工作空间及文件摘要，10分钟有效。确认时重新验证密码、摘要，再在所选父目录下新建随机命名的独立工作空间，不覆盖原空间。

恢复数据落盘后接入凭据写入本机凭据管理器并回读，最后注册工作空间。未完成的恢复保持锁定；失败目录保留用于核对，不视为成功恢复。恢复工作空间保留原证据归属以便追溯，自动同步、巡检停用，未完成同步变为暂停，连接检查失效。接入须重新检测后手动继续。

**恢复工作空间的审批、执行、补偿与自动巡检被锁定。** 历史记录可追溯，不重放旧批准。需在正常工作空间重新调查审批；本次未实现恢复空间重新开放执行的流程，也未实现原地覆盖恢复、全应用/聊天恢复、云备份或跨版本迁移承诺。
