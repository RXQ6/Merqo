# 经营分析：同窗口切换

2026-10-17 根据用户最新确认替代原独立窗口设计。点击主侧栏“经营分析”，在同一个 BrowserWindow 内显示分析界面；“返回会话”切回原会话界面。保留分析页分组导航、浅色布局和数据。

## 实现

- 原 retail:window IPC 保留调用签名，只验证本机工作空间和主 frame，再向调用方发送 retail:surface 导航事件；不创建、聚焦或关闭其他窗口。preload 仅暴露类型明确的订阅及取消订阅。
- App 持有页面状态。会话界面和首次进入后的分析界面保留挂载；非活动区域 hidden + inert，分析证据抽屉只在分析界面活动时注册 Escape 层。返回后继续原会话和分析筛选。
- 当前界面以 view=retail 保存到窗口 URL，正常退出后随原窗口恢复。旧版 surface=retail 配套窗口在读取窗口状态时合并；优先保留会话窗口的路由与尺寸。仅有旧分析窗口时转换为普通窗口的分析界面。用户主动创建的现代多窗口不去重。
- 本次不修改业务数据库、模型配置、调查和审批规则。

## 验收

1. 点击经营分析，窗口数量和窗口 ID 不变，通用侧栏隐藏，分析页保留三组导航。
2. 重复进入不新增窗口；返回会话，再次进入时保留分析页与筛选条件。
3. 伪造工作空间的入口调用仍被拒绝。
4. 正常退出后重启只恢复原窗口和所选界面；旧双窗口配置可迁移。
