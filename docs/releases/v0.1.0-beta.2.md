# Merqo 0.1.0-beta.2 — Windows Preview

Windows x64 预览版，2026-10-18。新增组合装、赠品、会员价、可售报价的明确业务契约，修复毛利调查的主张/证据复核与广告金额口径，补齐大数据毛利分页、调查暂停恢复和本机升级验收。

## 本版变化

- 固定业务集 48 个样例全部可执行并通过，包括审批、执行故障与业务边界检查。
- 广告数值观察由代码生成并校验；毛利 Reviewer 按快照描述、条件算术、因果与收益承诺分别检查证据，保留缺证与拒绝路径。
- 毛利导入最多十万行、32 MB；服务端默认每页 30 行，搜索/分页保留精确的完整作用域合计，导出明确限定当前页。
- 调查可暂停，实际退出后恢复；冻结证据、工具记录和累计最多 14 次调用预算保留。显式继续新增五分钟执行期限，旧运行迟到结果由 epoch 校验阻断。
- 调查复用 AgentBackend 的隔离推理能力与生命周期，未向调查开放通用聊天工具。

## 已验证

- 232 项回归测试、1725 次断言通过；领域/Electron 类型检查、真实 stdio MCP 和完整桌面构建通过。
- 第三批真实模型完整 15 次：毛利、库存、广告各 5/5，观察到禁止动作事件 0。前两批失败和校准记录全部保留。这是三个固定合成异常各重复五次，不代表生产准确率。
- 十万行毛利、连续 30 次生产 worker 查询，当前主机预热缓存下 p95 899.382 ms；包括 worker 启动、数据库连接和传输。导入约 45.526 秒。
- Windows 11 build 26200：真实 NSIS beta.1→beta.2 升级、同版本重装、首启、暂停/重启/恢复、三场景 MCP/Skill、模拟执行回执幂等、分页及卸载通过。升级和重装保留数据/设置/原回执，卸载保留用户数据。安装流程使用隔离配置和本地模型协议夹具，和真实模型质量评测分开记录。

## 已知限制

这是未签名预览版，Windows 可能提示未知发布者；没有自动更新服务。当前仍是本地分析与模拟审批/执行，不支持真实平台写入或多人身份授权。

完整 M5/PRD 发布门禁尚未通过：暂无干净 Windows 虚拟机及其他系统版本验收；库存/广告十万行、冷缓存、并发、低配性能和完整安全对抗尚未覆盖。外部 SKU、异常销量、延迟事件及一层组合装等业务契约保留明确边界。库存自由文本数字尚无广告同等级确定性核验。零观察越权事件不等于完整安全证明。

完整证据见仓库的 `docs/M5-local-acceptance.md`、`docs/M5-live-evaluation.md` 和 `docs/verification/`；`retail:eval --release-gate` 仍返回 `releaseReady: false`。
