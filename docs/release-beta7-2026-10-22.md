# Merqo 0.1.0-beta.7

本版合并三批本地场景化开发，具体范围见[交付说明](three-batch-delivery-2026-10-22.md)。

- 新增业务实体：按来源、店铺、商品规格及仓库/活动聚合证据、调查、方案和任务。
- 新增带冻结上下文的只读模型问答；保留对话、引用、未知项及明确离线导览。
- 新增业务任务：负责人、截止日期、优先级、处理状态、历史、审批/模拟执行关联。
- 新增本机到期提醒、单次/周期快照复查、明确开启的巡检发现转分析任务。
- 新增场景标签、经营方法、专题、不可覆盖的经营案例、JSON导出与同范围经验复用。
- 修复备份遗漏经营规则/商品映射数据库，以及任务保存后的表单重挂载和新增读取请求并发分类。

数据库升级至schema 10，迁移前保存备份。请勿使用beta.6读取升级后的配置。更新检查仍采用GitHub Releases和手动下载安装，不会自动执行安装器。
