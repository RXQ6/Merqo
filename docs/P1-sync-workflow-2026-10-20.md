# 平台接入向导与同步任务

> 后续开发：通用字段映射、质量隔离、事件去重、预览确认入库和批次对账已实现，见[最新入库工作流](P1-ingestion-workflow-2026-10-20.md)。下文记录此前交付范围及真实平台尚缺的准备，不能将历史“待开发”当作最新状态。

2026-10-20，开发版已实现。此功能晚于已发布 beta.5，尚未重新打包发布。用户尚未开通抖店应用，本轮真实平台调用为0。

## 用户链路

经营分析 → 平台接入 → 配置连接 → 检测只读连接 → 选择窗口和每页条数 → 创建任务 → 暂停 / 从断点继续 / 失败重试。

默认是明确标注的合成演练，可选正常分页、第2页限流两次后恢复、第2页响应无效。真实模式要求用户已有店铺订单只读授权，填写店铺 ID、App Key、App Secret、Access Token及到期时间。向导不代办应用创建，不实现 OAuth 浏览器授权或自动续 Token。接口检查成功仅证明当前订单接口可读，不证明手工声明的店铺 ID 已认证或数据完整。

## 已实现

- 任务持久化：等待、执行中、等待重试、暂停、需处理授权/配置、失败、拉取结束待映射。
- 固定查询窗口不超过24小时，每页1至100条、每任务最多100页。同一连接配置只允许一个等待/执行/重试/暂停任务。
- 暂存页与断点在同一 SQLite 事务提交，以任务 ID 和页码唯一约束防止同一页重复提交。显示的“收到条数”不是已去重订单数。
- 暂停会取消网络请求并更新任务版本，迟到响应不能提交。暂停操作针对指定任务的最新状态，避免界面轮询稍旧而无法暂停；继续和重试仍校验版本。
- 网络超时、HTTP429及502/503/504会退避，单页最多3次自动尝试；无效响应和平台拒绝停止并显示原因，允许显式重试。分页总数变化、页码异常、数量不足不推进断点。
- 重启后保留已提交页和断点，运行/等待任务恢复为暂停，需手动继续；退出后不运行，不在启动时自动发起平台请求。
- 配置变更使旧未结束任务失效并取消执行。当前更新授权也视为配置变更，必须新建任务，不能混用不同授权下的旧断点。
- 凭据通过现有加密凭据服务按工作空间保存，不进入普通配置、同步数据库或 worker 输入。分页原文用工作空间密钥 AES-256-GCM 加密后暂存，页面只返回计数、摘要和时间回执。
- Renderer不能指定数据库路径、工作空间或回写分页结果；内部 claim/page/failure 协议不在公开请求白名单。

## 验收证据

全量领域305项通过、2864断言、34文件。专项10项通过，覆盖分页、断点、迟到响应、重试预算、恢复、配置变化、授权过期和公开协议边界。领域及Electron类型检查通过，main和renderer构建通过。

实际Electron隔离流程5项通过：配置向导及检查；运行中实际重启后继续并完成7页7条合成记录；无效页手动重试不重复暂存；限流后自动恢复；加密凭据和分页核验。额外从真正的凭据后端读取暂存密钥并解密分页，验证7个唯一合成ID；数据库/WAL不含样本原文或测试密钥，Renderer拒绝伪造分页提交，未检查的真实连接不能开始拉取。演练结果没有进入CSV经营指标。

## 还未完成

当前交付的是“请求取得 → 加密暂存”。订单/支付/售后映射、订单实体去重、业务字段校验、确认入库及后台对账仍待开发；拉取结束明确显示“待映射”，不能称同步成功入账。真实平台鉴权、店铺身份、权限、限流和数据完整性均待应用开通后联调。

原始响应可能包含平台返回的业务/个人字段，只允许本机加密暂存，不在UI/日志/导出展示；业务表中未采集买家姓名、电话或地址。后续映射必须按字段最小化处理。尚无暂存清理或解密导出入口；备份暂存时需一并保留凭据存储中的密钥。任务列表显示最近50项，每项最多100页。多店铺并行连接、跨窗口自动增量调度、跨授权续传、自动Token续期及平台写入不在本轮范围。
