# Merqo 0.1.0-beta.8：复查页排版修订

保留beta.7的三批本地功能，修正最终截图复核发现的复查页内边距问题：巡检联动表单、到期提醒、复查计划的正文与卡片标题使用统一基线；确认说明改为上下布局，窄窗口继续单列。

本版只修改CSS及版本信息，领域逻辑和schema 10不变。业务基线为beta.7的391项全量回归、独立旧schema9升级检查和34条实际安装验收。本版补做实际安装、带已有业务数据的六项加载后宽窄窗口及卡片对齐检查、版本更新检查和卸载保留配置。
