# 商品映射与共同窗口契约

2026-10-19，实现前约束。映射是本地管理员显式声明，带独立来源、店铺、渠道、场景、原 SKU/规格、广告活动范围、有效日期、统一 SKU/规格、版本和原因。禁止模糊名称/规格推测；广告无规格时仅允许显式映射给出目标规格。映射不改原记录、不覆盖旧调查，也不授予真实平台身份。

同一输入身份和生效日不能存在多条适用映射；新增、修改、停用都生成不可变版本。调查创建时冻结当前映射及旁证，后续修改不回填旧调查。

跨场景联合分析仅在 source 类型、店铺、渠道、统一商品与规格一致，业务窗口一致，各来源声明完整且覆盖共同窗口，并且每场景范围唯一时成立。共同覆盖为各来源范围交集，完整截止为最早水位，不能用最新来源时间替代慢来源。库存/广告对照窗另行核对。多仓库、多 Campaign、缺规格/声明/窗口、截断、过期均明确待补证，禁止自动汇总。七日广告/库存不能与单日毛利强行合并。

“可作联合描述”只支持并列观察，不表示因果归因、净利润、真实平台认证或执行授权。调查报告、只读 MCP、导出与 UI 应展示冻结共同窗口、映射版本、来源缺口。旧 v1 调查保留原语义；新 v2 调查采用严格来源与共同水位契约。
